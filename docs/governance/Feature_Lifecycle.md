# Feature Lifecycle

Status: Draft ATOS v1.1 governance document

## States

1. Idea
2. Hypothesis
3. Specification draft
4. Laboratory experiment
5. Validation candidate
6. Development implementation
7. Regression candidate
8. Release candidate
9. Released
10. Deprecated or rejected

## Promotion Rules

- Idea to hypothesis: state expected effect and reason.
- Hypothesis to specification: define inputs, outputs and evidence plan.
- Specification to laboratory: confirm scope and risk.
- Laboratory to validation: produce initial evidence.
- Validation to development: evidence sufficient for implementation.
- Development to regression: code complete and reviewed.
- Regression to release candidate: tests and Hermes evidence complete.
- Release candidate to released: release checklist complete.
