# Deprecation Policy

Status: Draft ATOS v1.1 governance document

## Purpose

Prevents unsupported legacy behaviour from persisting silently.

## Deprecation Record

Each deprecation must state:

- Affected engine, parameter, output or document.
- Reason.
- Replacement or migration path.
- First deprecated version.
- Planned removal version, if any.
- Compatibility impact.
- Regression evidence.

## Rules

- Released files are not edited in place.
- Deprecated behaviour remains documented until removed.
- Removal requires changelog entry and migration note.
