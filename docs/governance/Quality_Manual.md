# Quality Manual

Status: Draft ATOS v1.1 governance document

## Purpose

Defines mandatory quality gates for Austin Trading Engine research, engineering, documentation and release work.

## Quality Gates

### Specification Gate

- Purpose and scope defined.
- Inputs, outputs and defaults documented.
- Constraints and non-repainting rules stated.
- Risks and assumptions recorded.

### Engineering Gate

- Pine Script v6 standards followed.
- No lookahead or repainting logic.
- Engine interfaces preserved or migration documented.
- Regression case added or updated.
- Documentation impact assessed.

### Research Gate

- Hypothesis written before evaluation.
- Data source and date range recorded.
- Method and evaluation criteria stated.
- Negative and inconclusive results recorded.
- Reproducibility manifest attached.

### Release Gate

- Affected specs updated.
- Regression evidence complete.
- Hermes validation artefacts archived.
- Changelog updated.
- Version and tag plan confirmed.
- Waivers, if any, documented and approved.

## Waivers

A waiver must include: reason, affected requirement, risk, mitigation, owner, expiry date and approving role.
