# Project Review Standard

Status: Draft ATOS v1.1 governance document

## Review Types

- Operational readiness review.
- Architecture review.
- Research methodology review.
- Release readiness review.
- Risk review.
- Documentation drift review.

## Minimum Review Output

- Scope reviewed.
- Evidence reviewed.
- Findings.
- Risks.
- Required amendments.
- Decision/recommendation.
- Confidence level.
- Owner and follow-up date.

## Cadence

- Operational readiness: quarterly during active development.
- Risk: monthly or after critical/high-risk events.
- Documentation: every release and monthly during rapid development.
- Architecture: before major interface changes.
