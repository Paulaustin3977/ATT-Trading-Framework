# Engineering Decision Record Standard

Status: Draft ATOS v1.1 governance document

## Template

```markdown
# EDR-000: Title

Date:
Status: Proposed | Accepted | Rejected | Superseded
Owner:

## Context

## Decision

## Alternatives Considered

## Consequences

## Risks

## Validation/Evidence

## Supersedes / Superseded By
```

## When Required

- Engine interface changes.
- Architecture changes.
- Major dependency/tooling decisions.
- Release-process changes.
- Decisions that materially affect reproducibility, validation or maintainability.
