# XAUUSD M15 Backtests

Store reproducible MT5 Strategy Tester evidence here.

## Required artefacts per run

- HTML or XML Strategy Tester report
- `.set` input preset
- Test date range
- Broker and symbol name
- Modelling mode
- History quality
- Initial deposit and leverage
- Spread and commission assumptions
- Screenshot of headline metrics
- Notes explaining the purpose of the run
